Lire ses mails sur sa montre Wear OS, même sans le téléphone

Les notifications, c'est bien, mais elles disparaissent dès que le téléphone est loin. Voici comment relever vos mails directement depuis la montre, en Wi-Fi ou en 4G.

1. Ce qu'il vous faut

  • Une montre Wear OS 3 ou plus récente (Galaxy Watch 4 et suivantes, Pixel Watch, TicWatch…).
  • Une connexion sur la montre : Wi-Fi, 4G (modèles LTE) ou le Bluetooth du téléphone.
  • Une appli de messagerie autonome qui parle IMAP, comme WatchMail.

2. Gmail : créer un « mot de passe d'application »

Google refuse votre mot de passe habituel dans les applis de messagerie tierces. Il faut un mot de passe spécial de 16 lettres, créé une seule fois :

  1. Activez la validation en deux étapes dans votre compte Google, rubrique Sécurité. C'est obligatoire.
  2. Toujours dans Sécurité, cherchez « Mots de passe des applications » (ou tapez-le dans la barre de recherche du compte Google).
  3. Donnez un nom, par exemple « Montre », puis copiez les 16 lettres affichées.
  4. Collez ce code à la place de votre mot de passe dans l'appli de mail.
Ce code ne donne accès qu'aux mails, et vous pouvez le supprimer à tout moment depuis votre compte Google : la montre est alors déconnectée.

4. Ménager la batterie

  • Relevez seulement la boîte de réception, pas tous les dossiers.
  • Laissez la montre passer par le téléphone quand il est proche : le Bluetooth consomme moins que le Wi-Fi ou la 4G.
  • Gardez les longues lectures pour le téléphone, et faites le tri au poignet : supprimer, archiver, marquer comme lu.

5. Ça ne marche pas ?

  • « Identifiants incorrects » avec Gmail : c'est presque toujours le mot de passe habituel au lieu du mot de passe d'application.
  • Rien ne se passe : vérifiez que la montre a une connexion (Paramètres › Connexions).
